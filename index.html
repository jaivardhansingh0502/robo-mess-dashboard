SECTION 02 // REAL-WORLD CHALLENGE

THE WAREHOUSE CRISIS: CHAOS AT SCALE

Modern high-density fulfillment centers demand hundreds of autonomous mobile robots operating simultaneously in narrow aisles. Traditional centralized dispatchers fail as fleet size scales.

NAIVE DISPATCH DEADLOCK SIMULATION NO TIME-SPACE RESERVATION
Path: R1(X) ⨯ R2(Y)

01. Aisle Congestion & Deadlocks

When multiple AMRs navigate shared narrow corridors without space-time reservation, robots create head-on blocking deadlocks requiring manual human intervention.

02. Centralized Bottleneck & Single Point of Failure

Central cloud planners introduce high round-trip latency (250ms+). If the central server or Wi-Fi drops, the entire warehouse fleet freezes in place.

03. Uncoordinated Task Bidding & Battery Starvation

Static task assignment ignores dynamic robot state—assigning long-distance jobs to low-battery robots, leading to mid-aisle vehicle shutdowns.

04. Kinematic Incompatibilities in Real Time

Grid paths assume robots are zero-dimensional points. Real physical AMRs possess mass, inertia, and non-holonomic turning radii that cause collisions during continuous motion.

SECTION 06 // DECENTRALIZED AUCTIONS

CBBA: CONSENSUS-BASED BUNDLE ALGORITHM

How robots evaluate bids without a central server. Mathematical scoring balances urgency, distance, battery percentage, and existing workload.

Bidding Score Function

Each AMR \(i\) computes marginal reward \(c_{ij}\) for task \(j\). The bid decays exponentially with Euclidean distance, scales with priority and battery health, and penalizes heavy current workloads:

c_ij = Priority_j · exp(-λ · d_ij) · (Battery_i / 100) · (1 / (1 + Workload_i))

SECTION 07 // SPACE-TIME PATHFINDING

CBS: CONFLICT-BASED SEARCH + SPACE-TIME A*

Resolving multi-agent conflicts without gridlocks. CBS detects vertex collisions and edge swaps in space-time (x, y, t) and branches constraints until paths are guaranteed conflict-free.

SPACE-TIME INTERSECTION SANDBOX TWO-LEVEL CONSTRAINT TREE

High-Level Constraint Formulation

When two robots approach an intersection at the same predicted time step \(t\), CBS formulates an explicit constraint:

Constraint: ⟨ Agent R2, Location (5, 3), Time t = 4 ⟩

The low-level Space-Time A* search replans Agent R2's trajectory with a temporary WAIT action at \(t=3\), allowing Agent R1 to clear the corridor without slowing down the global warehouse throughput.

SECTION 08 // REAL-TIME KINEMATICS

ORCA: OPTIMAL RECIPROCAL COLLISION AVOIDANCE

While CBS handles global space-time routing, ORCA operates at 50Hz on each robot's motor controllers for continuous 2D local collision avoidance.

VELOCITY OBSTACLE (VO) CONE GEOMETRY 50/50 RECIPROCAL EVASION
LOOKAHEAD HORIZON (τ): 2.0s

Reciprocal Velocity Sharing

Given relative position \(\mathbf{p}_B - \mathbf{p}_A\) and combined radii \(r_A + r_B\), the Velocity Obstacle \(VO_{A|B}^\tau\) defines collision velocities. The minimum evasion vector \(\mathbf{u}\) is shared reciprocally:

v_A^safe = v_A^pref + 0.5 · u   |   v_B^safe = v_B^pref - 0.5 · u

Because both AMRs know their peer will assume exactly 50% of the evasion effort, neither robot hesitates or deadlocks. Smooth, fluid passing is achieved at full cruising speed.

SECTION 12 // FAULT TOLERANCE

FAILURE RESILIENCE & DYNAMIC REPLANNING

What happens when a robot suddenly breaks down or runs out of battery mid-aisle? ROBOMESS automatically initiates a multi-stage consensus re-auction and trajectory bypass.

1

Hardware Fault Detected (Heartbeat Timeout)

AMR-03 motor driver alerts a stall. DDS heartbeat lapses for 150ms. Node marked OFFLINE by peer monitors.

2

Task Orphan Released

Assigned pallet order is immediately detached from R3 and returned to the global unassigned task auction pool.

3

CBBA Re-Auction Triggered

Active fleet (R1, R2, R4, R5) calculates fresh marginal bids. Task is seamlessly reallocated to AMR-04 (Echo).

4

CBS Space-Time Detour Replanning

Disabled robot R3 is converted into a dynamic static obstacle. Other AMRs replan their paths to safely bypass the stalled aisle.
